# 🌸 روضة أحباب الله

  **تطبيق إدارة متكامل للروضات | Kindergarten Management App**

  تطبيق شامل لإدارة روضة "أحباب الله" في صافيتا الغنومة، يدعم أدوار متعددة: المدير، المعلمة، ولي الأمر، والزائر.

  ## ✨ المميزات
  - 👨‍💼 **لوحة المدير** — إدارة الطلاب، المعلمين، المالية، النقل، الشهادات، وبطاقات الهوية
  - 👩‍🏫 **لوحة المعلمة** — إدارة الدرجات، الحضور، الأنشطة، والتواصل
  - 👨‍👩‍👧 **لوحة ولي الأمر** — متابعة التقارير، الرسائل، والإشعارات
  - 🌍 **صفحة الزوار** — عرض معلومات الروضة والتقييمات
  - ☁️ **مزامنة سحابية** — تخزين البيانات في قاعدة بيانات PostgreSQL
  - 📱 **APK للأندرويد** — تطبيق مبني باستخدام EAS Build

  ## 🛠️ التقنيات
  - **Frontend:** Expo SDK 54 (React Native)
  - **Backend:** Node.js + Express + TypeScript
  - **Database:** PostgreSQL (Supabase)
  - **Build:** EAS (Expo Application Services)

  ## 🚀 التشغيل
  ```bash
  npm install
  npm run server:dev   # تشغيل الخادم
  npm run expo:dev     # تشغيل التطبيق
  ```
